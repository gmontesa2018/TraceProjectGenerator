# Nomenclatura Oficial

Cada procedimiento pertenece a una categoría.

| Código | Categoría |
|---------|-----------|
| GES | Gestión |
| INF | Infraestructura |
| RED | Cableado de Red |
| COM | Comunicaciones |
| FIB | Fibra Óptica |
| CCTV | CCTV |
| ACC | Control de Accesos |
| POR | Porteros IP |
| CER | Cerraduras Inteligentes |
| AUT | Automatismos |
| PER | Seguridad Perimetral |
| ELE | Energía |
| VMS | Software de Gestión |
| QA | Control de Calidad |
| CAP | Capacitación |
| ENT | Entrega |
