# Roadmap

## Objetivo General

Desarrollar una plataforma que permita generar, administrar y documentar proyectos de tecnología utilizando ClickUp como motor de gestión.

- Integración con ClickUp
- Biblioteca base
- GitHub
- Control de versiones
